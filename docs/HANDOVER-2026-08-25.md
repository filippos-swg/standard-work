## ⚠ The brand gate — built here, still open on the live site

**In this package it works.** Step 01 of the Website configurator asks whether the client has a brand.

- *A Standard Work brand* — proceeds, no checklist, we already hold the files
- *An existing brand* — reveals a four-item checklist; brand prep is priced by what is missing and the total comes down as they tick

**On `standardwork.design` right now, none of that exists.** Stripe checkout is on and the configurator asks nothing about whether a brand exists. A person with no logo, no typeface and no palette can pay 8,000 SEK today and arrive in the inbox as a project that cannot be started — and will keep being able to until this is merged and deployed.

That gap is the argument for merging, not a defect in the build. If nothing else in this package survives review, this should.
